# kazibwe-foundation
Kazibwe Foundation School website developed as my Web Authoring semester project using HTML and CSS.

The website is based on the approved conceptual design and is being developed incrementally using GitHub for version control.

## Project Purpose

To create a simple, accessible, and responsive website that provides information about Kazibwe Foundation School.

## Website Structure

The website will be developed progressively based on the requirements provided during the project.

* Home Page
* Additional pages and sections to be developed as required
